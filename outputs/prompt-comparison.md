# V1 与 V2 Prompt 对照实验

## 实验设置

- 使用同一份 `outputs/summary.json`
- 使用同一个 DeepSeek 模型-DeepSeek-V4Flash-0731
- V1：仅要求分析数据摘要
- V2：限定唯一证据、分析问题、输出结构和禁止事项
- 原始输出：`outputs/v1-response.txt`、`outputs/v2-response.txt`

## 1. 事实准确性

V1 和 V2 都正确引用了类别的样本数和平均血糖水平。

例如，两者都正确识别：

- `Self-employed` 的平均血糖水平最高，为 112.65。
- `children` 的平均血糖水平最低，为 94.4。
- `Private` 的样本数最大，为 2925。
- `Never_worked` 的样本数最小，为 22。

因此，两份回答在主要数值上没有发现与 `summary.json` 不一致的内容。

## 2. 证据引用

V1 虽然列出了所有类别及其数值，但没有说明这些内容是唯一证据来源，也没有明确区分数据中的事实与额外解释。

V2 明确说明数字来自数据摘要，并逐项列出类别、样本数和平均血糖水平；还引用了两个相关字段的缺失数均为 0。V2 的证据链更清晰、更容易复核。

## 3. 限制说明

V1 只简短提到未进行显著性检验，以及各组样本量不均衡。

V2 更明确地说明：摘要没有标准差、标准误或置信区间，因此不能判断统计显著性；摘要也不能支持因果解释。V2 对证据边界的说明更完整。

## 4. 多余推断

V1 出现了超出摘要证据的内容：

- 添加了摘要中不存在的单位 `mg/dL`。
- 将类别名称扩展为“政府工作”“私营工作”等解释。
- 推测差异可能与年龄、生活方式或代谢特征有关。

这些内容不是 `summary.json` 中已有的事实，因此不应作为可靠结论。

V2 没有将类别差异写成因果关系，也没有编造新的数值。但它仍建议进行 ANOVA、箱线图等后续分析；这不是当前摘要支持的结论，并且超出本周只做简单聚合解读的范围。该问题说明 Prompt 约束能显著减少多余推断，但不能保证模型完全遵守所有边界。

## 对比结论

V2 的核心改进来自四项明确约束：唯一证据来源、禁止因果解释、证据不足时说明限制，以及固定输出结构。

与 V1 相比，V2 的数字更可追溯、限制说明更完整、因果风险更低。这个实验也说明：Prompt 可以降低幻觉和越界解释的概率，但仍需要程序或人工对输出进行检查。
