# 第 1 周复盘

V1 与 V2 的最大差异不在语言是否更流畅，而在证据边界是否明确。V1 只要求分析数据，因此虽然主要数值正确，却补充了摘要中没有的单位、类别解释，以及年龄和生活方式等原因推测。V2 明确规定唯一证据来源、禁止因果表述、要求说明限制并固定输出结构后，证据引用更容易追溯，因果风险也明显降低。但 V2 仍建议了 ANOVA 和箱线图，说明 Prompt 能降低越界解释概率，不能保证完全消除它。

本项目使用 Pydantic 保证 conclusion、evidence、limitations、next_step 四个字段完整且类型正确；程序还会检查 evidence.value 是否能在 summary.json 中定位。这些机制解决了输出格式不稳定和虚构数值的问题。

由于本项目是Deepseek改编版，无法使用OpenAI原生 output_parsed 功能，可能影响后续工作效率。且本程序不能保证 conclusion、metric 描述或后续建议完全符合证据边界，仍需人工审查。

本项目最可能出现的幻觉是把分组平均值差异解释为因果关系，例如声称工作类型、年龄或生活方式导致血糖变化；其次是补充摘要中没有的单位、统计显著性或医学背景。后续应继续坚持“程序计算，模型解释”，并对模型输出逐项回查。
